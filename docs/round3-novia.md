# Round 3: ViaVersion 转发开销实验(2026-10-07)

**问题**:两轮矩阵的 bot 都经 ViaBackwards(26.1 客户端 → 26.2 服务器)。Via 层本身花多少?原生 26.2 bot 会更快吗?

**答案:原生 26.2 反而慢 ~19%(一致、可复现),Via 转发开销 ≈ 0。**

## 设置

对照格:temurin25 + G1,heap 16G,p100,mixed,warmup 600s / measure 600s。

| 组 | 服务器插件 | bot 协议 | 轮数 |
|---|---|---|---|
| Via(R2 矩阵,10-02 采) | +ViaVersion/ViaBackwards | 26.1 经 Via | 3 |
| Via 同日对照(10-07) | 同上 | 同上 | 2 |
| noVia(10-07) | 无 Via | **原生 26.2**(`bots/add-26.2.js` 补丁) | 3 |

全部 0 掉线。同日对照用于剥离跨日环境漂移。

## 数据(mean MSPT,ms,测量窗 10min)

| 组 | rep1 | rep2 | rep3 | 中位 |
|---|---|---|---|---|
| Via 10-02 | 16.86 | 16.09 | 16.48 | 16.48 |
| Via 10-07 | 16.60 | 15.13 | — | 15.87 |
| **noVia 10-07** | **18.89** | **17.99** | **19.56** | **18.89** |

- 同日对比:noVia 比 Via **慢 19%**(18.89 vs 15.87),rep 分布不重叠(18.0–19.6 vs 15.1–16.6)
- 环境漂移:Via 跨 5 天仅 −3.7% → 差异不是环境噪声
- p95/p99/max 同方向恶化(noVia p99 ~30-37ms vs Via ~24-25ms),CPU% 与 RSS 无显著差异

## 解读

1. **ViaBackwards 26.2→26.1 转发开销可忽略**:包 ID 完全不变(见 `Protocol26_2To26_1` 类签名),
   实质近乎 passthrough —— 两轮矩阵的绝对数值不因 Via 层虚高。
2. **原生 26.2 更慢的机制未定位**。[推断] 服务器对原生 776 客户端可能启用了对(Via 翻译的)775
   客户端不启用的逐玩家代码路径(如新的注册表/实体特性);join game 包新增的 1 字节标志语义未知。
   未做 spark profiler 深挖——如需定位,下一步是对两组各采一份 `spark profiler` CPU 火焰图做差分。
3. **对 R1/R2 结论的影响:无。** 两轮矩阵所有组合同样经 Via,组间公平;绝对 MSPT 可视为"无 Via 下
   可能略差"的保守上界。

运行目录:`runs/20261007-00*-wsN`(noVia)、`runs/20261007-01*-ws0`(同日 Via 对照)。
